
# 🚢 Titanic Survival Prediction using Exploratory Data Analysis (EDA) and Logistic Regression

## 📌 Project Overview

This project focuses on **Exploratory Data Analysis (EDA)** and **Machine Learning** using the famous Titanic dataset. The objective is to analyze passenger data, identify the factors influencing survival, and build a **Logistic Regression** model to predict whether a passenger survived.

This project demonstrates the complete data analysis workflow, including data cleaning, visualization, feature engineering, model building, and performance evaluation.

---

## 📂 Dataset

- **Dataset:** Titanic Dataset
- **Target Variable:** `Survived`
  - 0 → Did Not Survive
  - 1 → Survived

## 📊 Project Workflow

### 1. Import Libraries
Imported the required Python libraries for data manipulation, visualization, and machine learning.

### 2. Load Dataset
Loaded the Titanic dataset using Pandas.

### 3. Data Exploration
- Displayed dataset information
- Checked data types
- Generated descriptive statistics
- Identified missing values

### 4. Data Cleaning
- Handled missing values
- Removed unnecessary columns
- Encoded categorical variables using One-Hot Encoding

### 5. Exploratory Data Analysis (EDA)
Performed visual analysis using:
- Count Plots
- Histograms
- Box Plots
- Heatmaps
- Correlation Analysis

### 6. Feature Engineering
Prepared the dataset for machine learning by selecting relevant features and encoding categorical data.

### 7. Model Building
Implemented a **Logistic Regression** classifier using Scikit-learn.

### 8. Model Evaluation
Evaluated the model using:
- Accuracy Score
- Confusion Matrix
- Classification Report
